[dbx](https://github.com/t8y2/dbx) 是一款可通过插件扩展能力的数据库客户端。它将数据库访问与 SSH、对象存储、消息队列、目录服务及 Kubernetes 等常见基础设施集成到统一的桌面工作流中。

本项目旨在收集开源的 dbx 插件，方便大家发现和使用优秀扩展。欢迎提交 Issue 或 Pull Request 补充更多插件。
