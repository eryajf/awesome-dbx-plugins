[DBX](https://github.com/t8y2/dbx) : 安装包 25 MB 驾驭 90+ 种数据库。支持桌面端、Docker、CLI，内置 AI 助手与 MCP Server。满足你对数据管理的想象！

![](https://camo.githubusercontent.com/1fdbabd69636010ad266e3bcebcebb63998f855dffc168a05b463db96ead8bc3/68747470733a2f2f646c2e646278696f2e636f6d2f6173736574732f726561646d652d6865726f2d32303236303832302e706e67)

从[v0.6.12](https://github.com/t8y2/dbx/releases/tag/v0.6.12)开始，软件支持了插件体系，开发者可以根据自己的需要，遵循官方插件开发约定，来开发解决各种问题的插件。

本项目旨在收集开源的 DBX 插件，方便大家发现和使用优秀扩展。欢迎提交 Issue 或 Pull Request 补充更多插件。
